### Purpose and Motivation:
To compare my _Custom Logistic Regression Method_ with the __Standard__ sklearn's _Logistic Regression Model_

## Summary Of Comparison:
- Custom Built Logistic Regression Method:
  It was slightly less accurate than the sklearn's Logistic Regression Model. However, it made it easier for me to interpret how it predicts. I discovered its loss function is different from Linear Regression Model.
- Sklearn' Logistic Regression Model:
  It is not a standard for nothing. This standard model can be achieved by adding the L2 penalty to a custom built model and scaling the features.

## Results:
Both Models show a high accuracy i.e. accuracy > 90 % .
However, sklearn's model leads by a few units.
